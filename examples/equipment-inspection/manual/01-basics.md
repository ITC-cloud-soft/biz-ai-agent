# 1. はじめに（ログインと SNS 連携）

この章の対象：すべての職員。設備点検の画面（`/`）で使う基本の操作です。

## ログイン

<a id="manual-basics-login"></a>

| 項目 | 内容 |
|---|---|
| URL | `/` |
| メニュー | 画面の「ログイン」 |
| 使える役割 | すべての職員 |
| 関連する画面 | [SNS 連携](#manual-basics-sns-link) |
| キーワード | ログイン、ログインできない、ID、パスワード、ログアウト |

設備点検の画面にログインします。

### 操作の流れ
1. 「ログイン ID」と「パスワード」を入れます。
2. 「ログイン」を押します。

### よくある質問
- **Q. ログインできない。**
  A. ログイン ID とパスワードを確かめてください。分からないときは施設管理者にお問い合わせください。
- **Q. ログアウトしたい。**
  A. 画面の右上の「ログアウト」を押します。

## SNS 連携

<a id="manual-basics-sns-link"></a>

| 項目 | 内容 |
|---|---|
| URL | `/` |
| メニュー | 画面の「連携コード」 |
| 使える役割 | すべての職員 |
| 関連する画面 | [ログイン](#manual-basics-login)、[通知の設定](#manual-basics-notify) |
| キーワード | SNS 連携、連携コード、Slack、LINE、WeChat、ボット、連携の解除 |

自分のアカウントに自分の SNS を結び付けます。連携できるのは本人だけです。

### 操作の流れ
1. ログインして「連携コードを発行」を押します。
2. 出た 6 桁のコードを、10 分以内に SNS のボットへ「link 123456」の形で送ります。
3. 「連携中の SNS」に出れば完了です。解除は同じ表から行います。

### よくある質問
- **Q. SNS の連携のしかたは？**
  A. 画面の「連携コードを発行」でコードを出し、ボットへ「link コード」と送ります。
- **Q. コードの有効期限が切れた。**
  A. もう一度「連携コードを発行」を押してください。前のコードは使えなくなります。

## 通知の設定

<a id="manual-basics-notify"></a>

| 項目 | 内容 |
|---|---|
| URL | `/` |
| メニュー | 画面の「通知の設定」 |
| 使える役割 | すべての職員 |
| 関連する画面 | [SNS 連携](#manual-basics-sns-link) |
| キーワード | 通知、通知が来ない、点検期限、オン、オフ |

点検期限の超過を SNS で受け取るかどうかを選びます。

### 操作の流れ
1. 「点検期限の超過を SNS で受け取る」のチェックを入れる、または外します。

### よくある質問
- **Q. 通知が来ない。**
  A. SNS 連携が済んでいるか、「点検期限の超過を SNS で受け取る」にチェックが入っているかを確かめてください。
