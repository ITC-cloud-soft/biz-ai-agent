# 2. 点検と修理依頼（SNS で）

この章の対象：設備責任者・施設管理者・点検員。点検期限の通知と修理依頼の承認は SNS で受け取ります。

## 点検期限の超過

<a id="manual-inspections-overdue"></a>

| 項目 | 内容 |
|---|---|
| 関係する画面 | `/`（SNS 連携・通知の設定） |
| メニュー | SNS の通知【対応のお願い】点検期限の超過 |
| 使える役割 | 施設管理者、設備責任者、点検員 |
| 関連する画面 | [修理依頼の承認](#manual-inspections-repair-approval) |
| キーワード | 点検期限、期限切れ、超過、点検していない、消火器、AED |

点検の期限を過ぎた設備があると、担当の点検員と設備責任者に SNS で知らせます。

### 操作の流れ
1. SNS の通知を開きます。
2. 現地で点検し、点検の記録を付けます。
3. 分からないことは、その SNS で AI に「期限を過ぎた設備は？」のように聞けます。

### よくある質問
- **Q. 期限を過ぎた設備はどれ？**
  A. SNS で AI に「期限を過ぎた設備は？」と聞くと、あなたの担当の分を答えます。

## 修理依頼の承認

<a id="manual-inspections-repair-approval"></a>

| 項目 | 内容 |
|---|---|
| 関係する画面 | `/`（SNS 連携・通知の設定） |
| メニュー | SNS の承認カード【承認のお願い】修理依頼 |
| 使える役割 | 施設管理者、設備責任者 |
| 関連する画面 | [点検期限の超過](#manual-inspections-overdue) |
| キーワード | 修理依頼、承認、差戻、承認カード、返信コード |

修理依頼は、設備責任者か施設管理者が 1 名承認すると確定します。依頼した本人は承認できません。

### 操作の流れ
1. SNS の承認カードの「承認」または「差戻」を押します。
2. ボタンが使えない SNS では、カードの返信コードで「承認 123456」「差戻 123456 理由」と返信します。

### 注意・決まりごと
- 依頼した本人は承認できません（ほかの承認者に回ります）。

### よくある質問
- **Q. 修理依頼を承認したい。**
  A. SNS の承認カードの「承認」を押します。ボタンが無い SNS では返信コードで返信します。
